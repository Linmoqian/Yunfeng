# 个人 Agent 工作区

工作区结构参考本机 LianAgent `a73bf448` 的 `AgentShell`、`ContextHeader`、工作台和团队组件。Yunfeng 的主题源仍为 `app/src/styles/tokens.css` 与 `ThemeProvider`；枫叶、云朵、云丛与云殿图像复用既有资产。

## 功能范围

左侧包含新建任务、资源、云殿、个人会话、云丛项目树、团队与设置。中间支持会话标签排序、分组、重命名、关闭和重新打开。左右分栏支持互换、调宽、64px 图标模式与重置。

主分栏和输入框使用 18px 圆角，卡片与页面右键菜单使用 11px，标签与按钮使用 8px。圆角和颜色均引用 Yunfeng token。

个人工作台提供任务、文件、设备与工具拓展入口。育种、基因组、品种筛选和模型训练入口已从迁移组件中排除。

现有对话继续使用 `taskService` 和 `useTaskStream`。新建标签只创建页面草稿；首条输入提交时创建会话。保留运行中消息排队、审批、分支、模型、思考强度与上下文信息。云殿既可在标签内打开，也保留 `/taskboard` 路由。

团队聊天、公告、成员与邀请是前端预览。文稿、设备条目、文件选择和项目名称保存在页面状态中；未接入新服务。关闭文稿标签或刷新页面会清除页面草稿，选择文件仅展示元数据。

## 右键菜单

输入框提供剪切、复制、粘贴和全选；页面提供复制选区、全选、返回与刷新，工作区额外提供分栏操作。标签与会话菜单优先处理右键，避免多份菜单同时弹出。菜单由 Ant Design 处理浮层和键盘导航。

## 验证

执行 `pnpm build`、`pnpm test` 和 `git diff --check`。28 项测试通过，覆盖原有会话归并、token、任务展示，以及新增分栏约束和标签批量关闭状态。

浏览器实际检查了欢迎页、草稿切换保留、分组、分栏互换、图标模式、双击恢复宽度、明暗主题、团队创建和本地聊天、云殿快照、右键全选、剪切和粘贴。新建真实会话后，首条用户消息与“个人工作区测试通过”回复同时显示。

云殿实时连接在验证时显示重连，尚未通过实时推送验收。构建提示部分分包超过 500KB。未进行移动视口和原生窗口完整验收。
