# 固定复杂工作流的三轮计时

日期：2026-10-18。补充单操作微基准，按工程师要求编排固定复杂流程、完整循环三次、逐环节计时，不调用真实 LLM。入口为 [workflow-compare.ts](../../server/scripts/research-live/workflow-compare.ts)，夹具与步骤在 [workflow-fixture.ts](../../server/scripts/research-live/workflow-fixture.ts)，复现命令见 [脚本说明](../../server/scripts/research-live/README.md)。

## 计时与编排

每轮在三个独立新目录执行完全相同的 36 个环节：Node 进程内、Node 管道、Rust 管道。三轮轮换先后顺序，无预热、无随机采样，不自动增减轮数。每组包含 100 节点 SQLite 初始化、观察等待条件、脚本 Hook 输入、规则决策、配置写入、基线统计、指标验收、规则反思、记忆落盘、暂停检查点、重建与恢复、复核事实、筛选统计、最终验收与完成事件。

系统 `Date` 提供 UTC 起止时间，`Date.now()` 提供毫秒墙上时间差；用于比较的耗时来自系统单调时钟 `process.hrtime.bigint()`，保存原始纳秒字符串与毫秒值。短环节墙上时间差为 0 是毫秒分辨率的限制；不使用虚拟计时器或夹具时间代替真实耗时。任务业务时间固定，便于逐步核对状态与结果。

Rust 主表耗时包含 Node 编码、管道传输、Rust 操作和响应解码，另保留 Rust 内部时间。每环节计时结束后才校验结果；不在环节之间写证据文件。报告将环节累计、扣除生命周期的累计和含环节间校验的时间分别列出。整体累计的中位数不等于各环节中位数之和。

决策与反思使用共用脚本中的明确规则，单独计时并标记 `shared-script`；它们不是 Rust 与 JS 推理性能对照。Hook 是脚本写入并读取本地控制事实，不运行真实 Pi 扩展桥。统计实验确实读取 256 条本地样本：基线统计全部样本，筛选阶段保留 128 条样本，各自落盘并回读验收。均值由 2 变为 4 是人为构造数据的统计结果，不代表训练或科学提升。

Node 管道与 Rust 管道在暂停后确实退出旧进程并启动新进程，使用 `--resume` 跳过种子写入并从 SQLite 恢复；Node 进程内组只重建领域实例，其第一轮启动还含首次模块加载。暂停没有人为等待时间。因此含启动的三个数字应结合生命周期差异理解。

## 本机结果

Apple M4 / macOS arm64，Node v26.7.0，Rust release/LTO，沿用独立 crate 锁文件。各项单位 ms，下表是三轮中位数：

| 项目 | Node 进程内 | Node 管道 | Rust 完整管道 |
| --- | ---: | ---: | ---: |
| 36 环节累计，含启动、暂停重建和关闭 | 24.555 | 97.987 | 19.318 |
| 扣除启动、重建和关闭 | 13.187 | 25.005 | 10.476 |
| 含脚本环节间校验 | 32.034 | 106.069 | 27.019 |
| 基线配置写入与文件验收 | 0.762 | 1.532 | 0.210 |
| 基线文件统计、落盘和产物验收 | 0.727 | 0.991 | 0.276 |
| 基线指标回读与数值验收 | 0.197 | 0.493 | 0.075 |
| 暂停检查点 | 0.797 | 1.181 | 0.804 |
| 读取暂停状态与关系树 | 0.241 | 0.399 | 0.373 |

36 环节累计的三轮原值：Node 进程内 24.555 / 18.254 / 29.934 ms；Node 管道 91.516 / 97.987 / 151.898 ms；Rust 管道 16.810 / 19.318 / 21.230 ms。完整表和每个环节的三次原值均在产物中，不丢弃慢轮。三次不足以估计稳定 p95，系统负载、缓存、GC、SQLite 绑定与版本均可能影响结果。

本次固定夹具中 Rust 的文件统计和写入路径较快；部分检查点与快照回读仍接近或慢于 Node 进程内。含重启的 Node 管道差距主要包含进程启动，不应外推为所有功能相同幅度的加速。生产 Runtime 仍未替换。
