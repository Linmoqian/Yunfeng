# 科研模式真实模型验收

日期：2026-10-15。当前状态：**未完成，上游认证阻塞**。

## 任务与验收条件

使用独立本地项目，取 Yunfeng `1db97af` 的科研 Runtime 源码快照：15 个 TypeScript 文件，共 68905 字节。来源清单与 SHA256 随实验保存，不读取个人数据或凭据作为实验材料。

目标是对比 gzip 压缩级别，在解压字节一致的前提下，相比 level=1 基线减少至少 1% 的压缩体积。脚本仅使用 Node 内置模块；由 Agent 写参数配置，再经 execute 调用 `node benchmark.mjs`。最终验收是脚本产出的 `report.json:completed == 1`，由真实压缩字节数、解压校验和基线比较共同决定。Agent 不得直接写指标或改脚本。

输入控制文件最初标记未就绪，用于验证 WAITING 不自旋；修改为就绪后应由文件 Hook 唤醒基线实验。基线完成后先反思，再等待工程师复核；暂停期间修改复核状态，应不触发行动。继续后应重新观察状态，选择参数、执行优化实验、反思并完成最终验收。
