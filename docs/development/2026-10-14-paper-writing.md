# 论文写作第一批迁移

专用界面分为三栏：左侧动态论文提纲，中间 Markdown 编辑和预览，右侧参考文献录入、提纲替换及文稿导入导出。通过工作台“论文写作”进入，可返回个人工作区。窄窗口依次将右栏和左栏折到纵向布局。

参考 LianAgent 的 `PaperWritingCard` 和 `research-tools` 交互；采用 Yunfeng 的 Ant Design、浅白淡紫及圆角 token。正文和标题继续使用现有 Rust `writing` 共享状态，不引入额外数据库或文稿事实来源。浏览器仅提供当前组件的编辑预览；原生窗口通过既有 SDK 同步。

文稿为 UTF-8 Markdown，最多 64 KiB。导入拒绝无效编码、二进制文本和非 Markdown 文件；替换已有内容前确认。导出生成 `.md` 文件。参考文献链接仅接受 HTTP/HTTPS，插入正文参考文献章节，不自动检索或验证文献。预览不执行 HTML，不加载远程图片。

当前草稿保留至应用退出。磁盘持久化、图片与数据素材库、PDF 编译导出和完整文献管理尚未迁移。

验证：41 项前端测试和生产构建通过。Tauri 原生窗口验证提纲建立、中文编辑、标题与表格预览、右栏文献插入、动态左栏提纲，并截图核对三栏布局。Markdown 导出在 Downloads 中生成测试文稿。文件选择期间受到窗口操作干扰，导入端到端与窄窗口尚未完成验收；导入解析边界已有自动化测试。已有大于 500 kB 的分包提示仍存在。
