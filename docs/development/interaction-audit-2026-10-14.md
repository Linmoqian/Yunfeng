## 已修正

| Before | After | Why |
| --- | --- | --- |
| 新启动和 Rust 重载可能遗留旧应用 | 启动入口退出旧开发树，runner 回收旧原生树 | runner 被终止后，原生子进程可能成为孤立进程 |
| 紧凑分栏的方向键反复吸附到 64px，鼠标按下后未获得键盘焦点 | 方向键逐步调宽，Home/End 吸附，按下边界时聚焦 | 让键盘调宽可实际使用 |
| 分组标签导航使用原始数组顺序 | 导航与分组渲染顺序一致并跳过折叠成员 | 避免激活标签与焦点对应不同标签 |
| 标签右键菜单退出后焦点留在页面 | 打开菜单时记录标签，Escape 后回到标签 | 可以继续用方向键切换标签 |
| 全局菜单记录非可聚焦子节点，键盘打开位置可能在原点 | 记录最近的可聚焦节点，缺少鼠标坐标时使用节点位置 | 恢复输入焦点和菜单定位 |
| 团队表单继承 64px 宽度后被挤成竖排 | 紧凑团队栏复用共享展开入口 | 表单恢复可读、可操作宽度 |
| 设置仍称文稿为前端预览 | 说明本机保存、图片、PDF 和设备配对当前边界 | 与实际能力一致 |

## 待处理与未验收

1. **后台生命周期**：旧独立 Node 服务仍占用 8787、8788、8000，原生启动日志出现 EADDRINUSE。它们已不属于旧原生进程树，需明确服务归属和接管策略；当前清理脚本不按端口杀进程。现有服务可提供会话，但不能据此认定新后台启动成功。
2. **项目目录**：项目行“在项目中新建会话”调用无目录参数的通用 onNew。源码证实此入口没有传入项目 cwd，尚未修复。
3. **草稿恢复**：标签关闭记录只保存标签元数据，组件卸载后的未发送输入未进入恢复记录。切换标签保留已实测；关闭、恢复与重启的草稿保护需要补齐。
4. **团队标题**：原生截图中中央右上分栏召回按钮与团队状态靠得过近，需要预留标题操作区域。
5. Windows/Linux 进程清理、原生菜单和窗口操作尚未实测。设备连接、团队同步、文件传输、SSH、窄手机布局与全部错误状态未完成端到端验收。
