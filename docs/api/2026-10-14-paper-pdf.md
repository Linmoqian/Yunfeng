# 论文 PDF 导出

## 接口元信息

| 项目 | 内容 |
| --- | --- |
| 接口标识 | `paper_export_pdf` |
| 用途 | 导出已保存文稿与本机素材 |
| 调用方 | main / component-writing |
| 提供方 | Rust component_sharing/export、pdf |
| 稳定性 | 实验性 |
| 引入版本 | 0.1.0 |
| 维护方 | Yunfeng 工作台 |
| 接口类型 | command |
| 调用方式 | 异步；磁盘和外部程序在阻塞任务执行 |
| 权限或认证 | allow-paper-export-pdf；Rust 校验窗口 |
| Content-Type | IPC JSON |

## 请求

无参数。Rust 从 SQLite 读取调用时文稿快照，原生保存对话框确定本机目标。前端不能传递正文、命令或保存路径。对话框打开期间的后续编辑不进入本次 PDF。

## 响应

| 返回值 | 类型 | 必定返回 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| true | boolean | 成功 | — | 文件已保存 |
| false | boolean | 取消 | — | 用户取消，未写入文件 |
| code/message | string | 错误 | 稳定代码/展示文本 | Promise 拒绝值 |

## 错误码

| 代码 | 含义 | 可重试 | 处理建议 |
| --- | --- | --- | --- |
| EXPORT_BUSY | 已有导出或保存对话框 | 完成后 | 等待 |
| EXPORT_UNAVAILABLE | 缺少工具或工具无法启动 | 配置后 | 安装 Pandoc、XeLaTeX |
| EXPORT_FAILED | 排版、图片、容量或写入失败 | 修复后 | 检查正文、字体、磁盘权限 |
| EXPORT_TIMEOUT | 排版超过 30 秒 | 修改后 | 减少内容并重试 |
| STORAGE_ERROR/STORAGE_VERSION | 库故障/版本不兼容 | 修复后 | 保留库并修复或升级 |
| FORBIDDEN | 窗口未授权 | 否 | 使用主窗口或写作窗口 |
| STATE_ERROR | 文稿状态不可用 | 重启后 | 重启应用 |

## 权限与安全

只允许已登记的 paper-asset 图片，拒绝外部图片和文件路径。原始 HTML 转义为文本，未启用原始 TeX。链接仅保留 HTTP/HTTPS/mailto。Pandoc 以 sandbox 模式转换受控 HTML；XeLaTeX 禁用 shell escape、限制文件访问。正文、路径、图片不写入日志。工具从 PATH 或绝对路径环境变量配置，不使用 shell 字符串执行。

## 行为约束

跨窗口最多一个导出；保存对话框可取消，排版开始后不提供主动取消。外部排版阶段共用 30 秒期限，超时回收子进程；Unix 同时终止本次进程组。最多 32 张不同图片、总计 6400 万像素，PDF 最多 32 MiB。临时文件退出时回收，生成成功后在目标目录写临时文件并原子替换；生成失败保留已有目标文件。没有自动重试或幂等标识，每次调用需再次选择目标。

本机需 Pandoc、XeLaTeX、相应中文字体。支持基础 Markdown、表格、图注和链接；不支持数学公式排版或期刊模板。素材预处理不计入外部程序 30 秒期限。

## 调用示例

`await invoke<boolean>("paper_export_pdf")`；返回 false 时显示“已取消导出”，true 时显示“PDF 已保存”。提示在文稿操作区域呈现。
