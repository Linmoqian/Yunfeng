# 看板工作流存储 API

## 接口元信息

| 项目 | 内容 |
| --- | --- |
| 接口标识 | `GET`、`PUT /api/taskboard/projects/:projectId/workflow` |
| 用途 | 保存和读取项目的工作流画布，不执行工作流 |
| 调用方 | 桌面任务看板 |
| 提供方 | 本机 Yunfeng Server；实验性，0.1.0 |
| 环境与认证 | 沿用服务现有本机访问边界；HTTP JSON，无额外认证 |

## 请求

| 字段 | 位置 | 类型 | 必填 | 默认值 | 约束 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| projectId | path | string | 是 | — | URL 编码，1–512 字符 | 项目标识 |
| workspace | PUT body | object | 是 | — | 序列化后不超过 2,000,000 个 UTF-16 代码单元 | 工作流画布快照 |
| version | PUT body | integer | 是 | — | 非负安全整数 | 上次读取的版本，新项目为 0 |

## 响应

成功返回 HTTP 200，JSON 包含 `projectId`、`workspace`、`version`、`updatedAt`。未保存时分别为请求的项目 ID、`null`、`0`、`null`；保存后版本递增，时间为 ISO 8601 UTC 字符串。

## 错误码

| HTTP / code | 含义 | 处理 |
| --- | --- | --- |
| 400 / BAD_REQUEST | 请求字段无效 | 修正请求 |
| 409 / VERSION_CONFLICT | 服务端已有更新 | 读取最新版本并解决冲突 |
| 500 | 读取或写入失败 | 保留草稿，检查服务后重试 |

## 权限与安全

沿用现有本机服务访问规则；文件保存在服务数据目录，数据库权限为 0600。调用方不得在快照中存放凭据。接口不访问项目路径、不执行节点。

## 行为约束

写入以 SQLite 事务和版本号防止并发覆盖；重复写入必须使用新版本。服务重启后记录保留。客户端只在成功导入旧本地草稿后清理旧数据。没有分页、缓存或自动重试；其他窗口的实时通知和工作流执行尚未接入。

## 调用示例

`PUT /api/taskboard/projects/demo/workflow` 的 JSON 请求体：`{"version":0,"workspace":{"tabs":[]}}`。

## 兼容性与变更记录

2026-10-28：新增实验性存储接口；读取旧版空操作的客户端需改用本接口。本接口不改变现有会话和任务数据。
