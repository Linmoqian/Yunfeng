# 本机对等团队节点接口

## 接口元信息

| 项目 | 内容 |
| --- | --- |
| 标识、版本 | `yunfeng-team-node`，实验性 v1，2026-10-17 |
| 调用方 | Agent、本机程序、已显式配对的邻居节点 |
| 提供方 | `team-service` crate 的可选 `node` feature |
| 协议 | HTTP/1.1 JSON，POST；仅 IP 字面量回环地址，无 TLS |
| 基础地址 | 启动输出的 `http://127.0.0.1:<port>` 或 IPv6 回环地址 |
| 认证 | 必填 `Authorization: Bearer <token>`；控制、成员与对等令牌分离 |
| 数据源 | 该节点目录的 SQLite，桌面与服务复用同一领域模块 |

## 控制接口

`POST /v1/local`，Content-Type 为 `application/json`，使用本机 `control.token`；未知 action/字段拒绝。每个请求必须有单一 Content-Length；拒绝 Origin、Expect 和 Transfer-Encoding；不支持 chunked、压缩和流式请求。

| action | JSON 字段 | 约束与行为 |
| --- | --- | --- |
| snapshot | 无 | 返回当前团队、邻居与文件清单 |
| create | name:string | 去首尾空白后1..80 Unicode字符，不含控制字符；owner 为启动时的节点名称；不能覆盖不同的活动团队 |
| message | id:UUID, text:string | 1..4000字符；同节点同ID同正文幂等，冲突拒绝；允许换行和制表符 |
| board | announcement:string, links:Link[] | 公告0..4000字符；links 最多16条，title 1..80字符，url 仅 HTTP/HTTPS、无登录凭据、最多2048字节；本地原子保存 |
| invite | 无 | 返回 `{address,team,ticket}`；票据十分钟有效，全节点最多32张有效票据；票据敏感，不写日志 |
| join | invitation:{address,team,ticket} | address 为邀请节点的完整回环基础地址，team 为 UUID，ticket 为64位十六进制字符串；不能更换不同活动团队；同票据同节点可重试 |
| sync | 无 | 逐个与当前团队最多8个直接邻居双向交换；失败保留本机记录，返回逐邻居结果 |
| share | name:string, data:string | 仅显示文件名，1..80字符，无斜杠、反斜杠、控制字符、`.`/`..`；data 是标准 Base64，解码最多1MiB，允许空文件 |
| file | id:UUID | 返回当前团队该文件事件的 `{kind:"file",name,data,sha256,size}`；size 为字节数，sha256 为小写十六进制摘要 |
| member | member:{id:UUID,profile:MemberProfile} | 新增或整体更新本节点托管的成员；不能改写其他节点的成员；每队最多128个 |
| grant | id:UUID, rotate?:boolean=false | 为本节点启用成员签发独立凭据；默认返回已有凭据，rotate=true 立即使旧凭据失效 |
| shutdown | 无 | 响应 `{stopping:true}` 后关闭监听与进程；保留数据 |

除 invite/sync/file/shutdown/grant 外成功返回 `NodeSnapshot`：

```json
{"node":{"id":"00000000-0000-4000-8000-000000000001","name":"节点","address":"http://127.0.0.1:19001"},"snapshot":{"installationId":"00000000-0000-4000-8000-000000000001","mode":"empty","team":null,"savedTeams":[],"messages":[],"participants":[],"board":"","links":[],"networkAvailable":false},"peers":[],"files":[]}
```

`snapshot` 业务字段沿用 [本地协作 IPC](2026-10-14-collaboration-action.md)；节点服务的新消息 name 为凭据绑定的发布成员名，memberId 为其 UUID；旧消息 memberId 可空并保留原作者，team.members 包括本机与直接邻居名称，可能重名，不作为身份依据。`networkAvailable` 表示存在已配对邻居，不代表在线。`peers` 仅返回各邻居的 id/name/address，不能获取其控制凭据或连接令牌。`files` 为 `{id,name,size,sha256,origin}[]`；不带文件字节。消息最多返回最近200条，入库顺序显示。

sync 响应为 `{results:[{node,ok,error?}],state:NodeSnapshot}`。HTTP 200 可能包含某个邻居 `ok:false`，调用方必须逐项检查；不自动重试，不把失败解释为删除或空数据。

## 成员接口与资料

`POST /v1/member` 使用 `grant` 返回的 `{memberId,token}` 中的成员 token。它只授予当前团队、当前宿主的该成员身份；不能用于控制或对等接口。token 是敏感的64位十六进制字符串，仅保存在本机私有数据库及 grant 响应，不能记录或显示。每次请求读取最新权限，停用与轮换立即生效；重启保留凭据。控制接口仍是本机管理员入口，可维护本机成员并恢复权限。

成员接口的所有字段均由严格 JSON 反序列化校验，未知字段拒绝；权限拒绝返回 HTTP 403 `NODE_FORBIDDEN`。

| action | 字段 | 返回 | 权限 |
| --- | --- | --- | --- |
| identity | 无 | MemberCard | 启用的有效成员 |
| snapshot | 无 | NodeSnapshot | 同上 |
| message | id:UUID,text:string | NodeSnapshot | contributor/editor；作者固定为凭据身份 |
| share | name:string,data:Base64 | NodeSnapshot | contributor/editor |
| file | id:UUID | 文件内容对象 | 启用的有效成员 |
| board | announcement:string,links:Link[] | NodeSnapshot | editor |
| robotAuthorize | operation:string | {authorized:true,memberId,operation} | robot，telemetry 只需启用；其他操作须 robotControl=true |

消息、文件和公告字段限制与控制接口相同。消息幂等键还绑定成员，不能重用其他成员的 ID。robotAuthorize 的 operation 包括 connect/disconnect/telemetry/emergencyStop 及登记 capabilities；非通用操作必须出现在 capabilities。此接口只有授权副作用，没有硬件执行、遥测或模型调用。普通成员不能调用 member/grant/invite/join/sync/shutdown。

`snapshot.participants` 是当前团队全部 MemberCard（最多128条，按本地入库顺序），空团队返回 `[]`。MemberCard 为 `{id:UUID,nodeId:UUID,profile:MemberProfile}`；id 为成员身份，nodeId 为托管宿主，不可混用。主机可以托管多个不同种类的成员。MemberProfile 整体替换，字段如下：

| 字段 | 类型/必填 | 默认值 | 限制与含义 |
| --- | --- | --- | --- |
| name | string/是 | — | 1..80 Unicode字符，无控制字符 |
| kind | human/agent/program/robot/是 | — | 身份类型，不决定权限 |
| access | observer/contributor/editor/是 | — | 只读/协作/编辑 |
| summary | string/是 | — | 0..240字符，无控制字符 |
| enabled | boolean/是 | — | false 拒绝所有成员请求 |
| robotControl | boolean/是 | — | 只允许 robot 为 true；界面创建默认 false，独立于协作权限 |
| assistant | object/null/否 | null | 仅 agent；对象完整包含 model、provider、skills |
| robot | object/null/否 | null | robot 必须提供，其他种类必须 null；对象完整包含 kind、model、capabilities |

assistant.model/provider 和 robot.model 为0..80字符，无控制字符。skills/capabilities 各最多16项不重复的1..80字符名称。robot.kind 为 vehicle/drone/arm/other；车辆能力仅 drive，无人机仅 takeoff/land/velocity，机械臂仅 joints/gripper，other 可登记自定义名称。资料只描述身份、能力与授权，不证明模型或设备已连接。未知字段拒绝。

控制接口登记示例（脱敏资料）：

```json
{"action":"member","member":{"id":"00000000-0000-4000-8000-000000000002","profile":{"name":"实验助手","kind":"agent","access":"contributor","summary":"整理实验结果","enabled":true,"robotControl":false,"assistant":{"model":"","provider":"","skills":["实验记录"]},"robot":null}}}
```

同 ID 更新资料会生成新事件；没有删除操作，使用 enabled=false 停用。成员资料按 `(clock,origin,id)` 的最新事件投影，旧事件迟到不会覆盖新权限；已有 id 的宿主不能变更，越权更新返回 `COLLAB_FORBIDDEN`。权限与资料本机提交后立即生效，邻居在 sync 后看到新资料。凭据不进入同步事件。TypeScript 父类与身份继承见 [成员 SDK](../../team-service/sdk/README.md)。SDK 中成员仅依赖 MemberService，服务仅通过 MemberTransport 发请求；connectMember 负责组装。原始 transport 需先经 createMemberService 包装再注入成员；该调用分层不改变本接口字段、权限或成员可见范围。

## 对等接口

`POST /v1/join` 使用邀请 ticket 作为 Bearer，body 为 `{ticket,node:{id,name,address},incomingToken}`。id 必须为 UUID，name 1..80字符，address 必须为规范化回环基础地址，incomingToken 是64位十六进制字符串。票据绑定首次成功的节点 ID；同 ID 相同身份/令牌可重试，其他节点拒绝。返回 `{node,team,incomingToken,events}`；incomingToken 是邀请方授予加入节点的团队范围访问能力，不能用于控制接口。

`POST /v1/exchange` 使用接收方为该发送节点签发的团队范围 Bearer，body 为 `{from:UUID,team:UUID,events:Event[]}`，返回相同结构，from 为响应节点 ID。from/team 必须匹配已配对记录。成员可转发团队内事件；接收方不会自动联系事件中的地址或获取磁盘文件。

Event 为 `{id:UUID,origin:UUID,clock:integer,team:UUID,change:Mutation}`；clock 范围为1..(i64::MAX-10000)。Mutation：

- `team`：`{kind:"team",name,owner}`，事件 id 等于 team。
- `message`：`{kind:"message",name,text,time,memberId?:UUID}`，time 为非负 Unix 毫秒（最多 i64::MAX），事件 id 是业务消息 ID。
- `member`：`{kind:"member",member:MemberCard}`；member.nodeId 必须等于事件 origin。
- `board`：`{kind:"board",announcement,links}`。
- `file`：`{kind:"file",name,data,sha256,size}`；字节数与 SHA-256 必须与内容相符。

每条事件只允许所属团队；同ID同内容忽略，同ID不同内容整批拒绝。每队最多1000条同步事件、序列化总量6MiB；批次最多1000条。批次校验、事件与业务投影在同一 SQLite 事务提交。原始 Base64 文件内容仅保存在事件中；业务快照与文件清单是同库派生视图。

## 错误与运行约束

成功 HTTP 200；请求字段、结构、限额、存储、版本和连接失败 HTTP 400；认证或团队授权失败 HTTP 403。错误 JSON 为 `{error:{code,message}}`，不回显上游正文、原始路径或凭据。主要代码：`COLLAB_INPUT`、`COLLAB_FORBIDDEN`、`COLLAB_LIMIT`、`COLLAB_STORAGE`、`COLLAB_SCHEMA`、`COLLAB_ACTIVE_TEAM`、`COLLAB_NO_TEAM`、`COLLAB_NOT_FOUND`、`NODE_FORBIDDEN`、`NODE_CONFLICT`、`NODE_UNAVAILABLE`；启动另有 `NODE_BUSY`、`NODE_CONFIG`。连接在完整请求前断开时可能无响应。

每进程串行处理请求，不增加运行时或线程池；TCP 接受队列16，每次处理一个连接。Header 最多16KiB、32项，请求/响应正文最多8MiB，读写有超时，主动关闭连接。连接超时3秒，单次对等请求总预算5秒；sync 十秒后不再开始新的邻居请求，最坏约十五秒完成。SQLite 锁等待最多两秒，期间本地事务已经确认的数据仍保留。调用方建议20秒超时；超时不能推断写入失败，应 snapshot 或使用原消息 ID 重试。两个节点同时同步可因串行等待超时，稍后重试；首版无后台调度。

公告按 `(clock,origin,id)` 最大值收敛；无人工版本合并，较晚墙钟时间不保证获胜。文件按事件 UUID 追加，不覆盖同名旧内容。宿主身份、成员资料、三类凭据、邻居、邀请与事件在重启后保留；重启须沿用节点名称、目录、端口。同一数据目录只允许一个实例，操作系统文件锁在退出或崩溃后释放。改变已配对地址/名称会拒绝复用连接。

控制和连接凭据仅存本机私有目录，不进入命令行、stdout、前端快照或验收报告；文件内容与消息未加密，依赖本机账号权限。邀请只授予一队的邻居能力，不能执行 shutdown 或读取其他团队。已配对节点视为受信任成员，事件暂不签名；本机回环的验证版本不开放局域网/公网，不支持自动发现、TLS、物理删除成员、撤销已配对凭据、历史压缩或跨机验收。桌面当前仍为本地 IPC，未启用独立节点网络 UI。

## 兼容性

独立服务协议实验性 v1。本次增加成员动作、成员入口与事件类型；交换事件前所有节点须升级，不支持新旧节点混合滚动运行。旧消息事件没有 memberId 时仍可读取和转发。

核心数据库从 user_version=1/2 事务升级至3，增加 team_members 与可空 messages.member_id。旧桌面团队补齐本机 human/editor，旧节点补齐本宿主 program（创建节点 editor、加入节点 contributor），不改写历史消息、公告或链接。节点表保留独立 version=1 标记，成员凭据存在同库 node_member_auth 表。未知更高核心版本拒绝打开。桌面 IPC 增加 member 动作和 participants/memberId 响应字段，原请求仍可反序列化，但消息和公告新增成员权限检查。
