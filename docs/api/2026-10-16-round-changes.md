# 单轮变更统计

## 契约

`GET /api/tasks/:id/git` 在既有响应 `git` 下增加可选 `round`，原 Git 提交权限与工作区字段保持原意。读取权限沿用任务与 Git 路由，未找到任务返回既有 404。

```json
{"round":{"id":"round-example","startedAt":"2026-10-16T00:00:00Z","completedAt":"2026-10-16T00:01:00Z","root":"/project","files":[{"filePath":"/project/source.ts","status":"modified","additions":4,"deletions":1}]}}
```

开发模式一次独立用户指令至 Agent 停止为一轮，工具往返、引导和运行中的排队消息属于同一轮；科研模式一次实验作业为一轮。下一轮执行前重建内容基线，已存在的脏文件只统计本轮增量。完成快照冻结；空轮不展示胶囊；没有历史基线的任务返回 `round:null`，不推算历史数据。此统计表示项目在该时间窗口内的内容差异，同期外部编辑也会计入，不能证明修改者身份。

`files` 包含所有本轮变更；界面最多展示前 20 项，总计仍包含其余项。二进制、链接和大文件的增删行数为 `null`，不伪造零行。敏感配置、凭据与构建目录排除。

## 持久化与副作用

沿用 Server TaskStore，增加每个任务的 `round-changes.json`，不迁移既有任务或资源数据库。版本为 1，原子替换，权限 0600，仅保留最新轮。执行前保存固定 HEAD 和已有脏文件内容；单文件文本上限 256 KiB，基线总文本上限 16 MiB，最多 2000 个候选路径；超限则本轮不建立统计并记录服务日志，Agent 可继续。

读取运行中轮次会计算并持久化最新统计；完成时清除正文基线，只保留统计。正文基线不会进入 API、任务快照或 SSE。统计异常或服务重启时未完成记录冻结为 `interrupted:true`，只显示中断前已记录的结果，避免重启后的其他编辑混入。缺失记录向后兼容；损坏或未知版本记录读取失败，不当作零变更。读取失败使用现有服务错误路径，界面展示重试入口。

统计使用 Git 只读命令及受控临时文件，不改仓库索引、提交或工作区，不执行远端请求。`git_changed` 事件携带 `scope:"round"`，仅提示前端重新读取。

## 验证

`server/test/round-changes.test.ts` 覆盖脏文件、新增、删除、提交、子目录范围、冻结、重启和下一轮隔离；`app/desktop/tests/changeSummary.test.tsx` 覆盖历史隔离、服务端总计、未知行数及 Escape 焦点恢复。
